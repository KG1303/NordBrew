# NordBrew
Why every single tea timer is shit? I made my own with AI for my preferences, with beautiful [Nord theme](https://github.com/nordtheme/nord), and preset for sencha tea. 
## Functions
* Look through your tea collection, quickly understand how much is left
* Quick sencha pattern for fast brewing
* Nice looking timer
## Installation
* Go to the [releases page](https://github.com/KG1303/NordBrew/releases)
* Download the apk file
* Launch it and install like any normal app
* If play store defence tells you not to install this app, press "Advanced", "Install anyways", if it says "App not installed", just try again with the same apk file
